# Angela Brown Career Roadmap Site

A simple interactive career site. No build step, no installs.

## Files

| File | What it is | Do you edit it? |
|---|---|---|
| `content.js` | Every word on the site | Yes. This is the only file you need. |
| `styles.css` | Colors and layout | Only to change colors (top of the file) |
| `index.html` | Page structure | No |
| `app.js` | Makes the page interactive | No |

## Before you publish

1. Open `content.js`.
2. Replace every `[bracketed placeholder]` with a real detail: proof numbers, your three-line stories, your email, and your LinkedIn link.
3. To make a contact line clickable, set its `href`, for example `"mailto:you@example.com"` or `"https://linkedin.com/in/your-name"`.

## Put it on GitHub Pages

1. On github.com, click **New repository**. Name it anything, for example `career-roadmap`. Choose **Public**, then **Create repository**.
2. Click **uploading an existing file**, drag in all five files from this folder, and click **Commit changes**.
3. Go to **Settings**, then **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then **Save**.
5. Wait one to two minutes. Your site is at `https://YOUR-USERNAME.github.io/career-roadmap/`.

## Share a specific step

Add `#step-4` to the end of the link to open Step 4 directly. Use `#step-1` through `#step-5`.

## To update later

Edit `content.js` on GitHub (pencil icon), commit, and the site refreshes in a minute or two.
